# NAS全自动24小时监测自选股 (AStock-AI-Tracker)

基于个人 NAS (如 TRIM/fnOS) 部署的**纯本地、全自动、确定性**股票复盘与交易辅助系统。

## 🎯 核心定位：拒绝幻觉，绝对的纪律防守
散户最大的敌人是“情绪化追高”和“主观臆断”。本项目不是用来“推荐牛股”的，而是基于严格的数学模型，生成**客观、冷静、不含任何主观判断的 If-Then 条件剧本**。

在最新的 v3 架构中，我们**彻底剥离了 LLM（大模型）参与交易逻辑生成**的环节：
*   **0 LLM 幻觉**：行情数字、支撑/压力位计算、命中判定 100% 由 Python 纯算力执行。
*   **100% 送达率**：摆脱了 LLM API 接口限流 (429) 的困扰，生成后直接通过 NAS 的 Cron 任务通道秒推微信。
*   **硬核对账**：早盘 08:45 生成的剧本，会以结构化 JSON 落盘，盘后 15:30 自动调用今日真实的 OHLC 数据进行逐条**程序化对账**，到底做没做到知行合一，一目了然。

## 🏗️ 双轨闭环系统设计 (v3 架构)

### 1. 🌅 早盘预案 (Morning Playbook)
*   **触发时间**：每个交易日 08:45。
*   **逻辑**：根据昨日收盘后的数据（均线、量比、近期高低点），自动计算出头顶最近的压力位和脚下最近的支撑位。
*   **输出**：纯模板输出 `If-Then` 操作剧本（例如：“若盘中上冲触及 15.30，视为放量试探”），并把条件持久化写入 `state/plan_*.json`。

### 2. 🌃 盘后对账 (Afternoon Reconcile)
*   **触发时间**：每个交易日 15:30。
*   **逻辑**：读取早盘的 `plan_*.json`，并获取今日最新收盘的 K 线数据。
*   **输出**：逐条核对早盘的条件是否被触发（命中/未命中），对今日形态给出程序化的定性结论（如：“冲高回落”、“破位”）。同时生成次日的盘前框架。

### 3. 🛑 节假日自动静默
*   内置了完整的中国 A 股交易日历（`trading_days.json`）。
*   利用底层 `wakeAgent: false` 机制，在周末、法定节假日**绝对静默**，不消耗任何资源，不打扰你的生活。
*   若是交易日遭遇网络或数据源故障，**必然推送告警**（不静默失效，保证让你知道系统状态）。

## 🚀 部署方法 (Hermes Agent / NAS)

1.  **准备配置文件**: 
    复制 `scripts/config.example.json` 为 `scripts/config.json`，在里面配置你要监控的自选股（支持沪深）。
    
2.  **设定 Cron 任务**:
    推荐使用 Hermes Agent 自带的 cron 功能进行调度，并开启 `--no-agent` 模式（直接将 stdout 推送至微信/Telegram）：
    ```bash
    hermes cron create --name astock_早盘预案 --schedule "45 08 * * 1-5" --script morning_runner.py --no-agent --deliver all
    hermes cron create --name astock_盘后对账 --schedule "30 15 * * 1-5" --script afternoon_runner.py --no-agent --deliver all
    ```

3.  **依赖**:
    纯 Python 3.11 标准库开发，无需安装第三方包（0 依赖：直接使用 `urllib` 获取腾讯实时行情、新浪主力资金流和巨潮公告）。
